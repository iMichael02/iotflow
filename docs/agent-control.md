Instruction document for TypeScript unit test is triggered when user uses /ts-unit-test or ask the agent to write unit tests. It should not be triggered when user ask Claude to write TypeScript unit test for components or layers written in Java, C++ or Go.
The enforcement on contract between TypeScript layers blocks coding agent makes insufficient changes to the flow or tries commit those changes to GitHub. The instruction is insufficient since it does not explain how the agent should respond when a TypeScript layer contract is violated or provide a fallback path for recording or reviewing the blocked change instead of forcing an unsafe commit. It also omits the expected behavior for preventing insufficient flow changes and GitHub pushes that bypass the contract.
